# SaltsCore 0.1.000 candidate status

This is a **Draft migration candidate**, not a published release or a claim of
complete original behavior parity. PRs #72 and #94 remain Draft and unmerged.
No release tag or package has been published by this work. The original
2,975-file / 610-explicit-public-function final gate remains mandatory, and
AC/Levenshtein remain deferred without receiving migration credit.

## Implemented candidate changes

- Integrate the native SIMD branch with the current first-party ASN1/Crypto
  source layout and the existing isolated M5 source-owner work. The production
  CNet/Crypto cutover is still incomplete; the test-only exception is not a
  production SDK solution.
- Preserve `Salts::SIMD` as a fixed static module with plain C declarations,
  32 original numeric functions and 14 native lane shapes. Its source/public
  surface contains no `SALTS_C_API` or SIMD DLL import/export machinery.
- Restore the original seven-function MPMC priority queue to the existing
  Concurrency owner, the eight original concurrency test programs, and the
  original installed leader/followers consumers. Correct two reproduced TSan
  races without changing the public layouts or queue policies.
- Restore the original native error registry to Core, including borrowed
  descriptor/string lifetimes, registration capacity and error classification.
  Correct the reproduced `INT_MIN` signed-overflow path. The original reflected
  enum metadata is still an upper-layer obligation.
- Assemble original USB, Playback, Serial and Capture modules as their real
  shared native owners. Preserve original inputs and tests, with exact donor
  copies of adapted build files. Serial uses private typed storage with the
  original deep-copy/move/destroy semantics, without a reverse CSTL dependency.
- Restore the seven original Zstd adapters in Core with the original pinned
  static provider. ELF qualification checks the actual private-symbol boundary
  and rejects a second Zstd DSO.
- Select the real Linux epoll/io_uring sources on Android, and preserve native
  initialization failures. Fix installed ASN1 lookup under cross-toolchain
  find-root rules while retaining rejection of an already imported foreign
  owner.
- Add candidate archives, installed consumer graphs and the guarded version
  workflow. Production publication admission is explicitly disabled until
  verified CI receipt binding and clean-runtime dependency closure exist.

The relevant implementation and boundaries are documented in
[MPMC](original-mpmc-migration.md), [errors](original-error-migration.md),
[Zstd](original-zstd-migration.md), [USB](../usb/MIGRATION.md),

[Capture](../capture/MIGRATION.md), and

## Confirmed release blockers

1. **Original completeness evidence is unfinished.** The final command
   `python tools/check_full_source_migration.py --require-complete` returns 1.
   All 924 native file obligations and 610 original public API obligations
   remain unqualified in the strict ledger. The historical 573 missing/changed
   and 351 present-but-unqualified snapshot is retained. These are acceptance
   statuses; adding source or passing a partial suite does not close them.
   SIMD has a separate 32-function supplement and requires four current-source
   native profiles. Its evidence does not close historical/reflection debt.
2. **AC/Levenshtein remain deferred by the user.** Their five original files and
   26 public functions stay in the frozen final baseline and cannot be waived
   by a candidate receipt.
3. **Capture leaks in the pinned provider.** The original POSIX test fails LSan.
   An independent miniaudio-only reproduction confirms a leaked Pulse context
   after failed connection initialization. A two-line proposal, applied only to
   a temporary experiment, preserves the `-203` error and eliminates that
   observed leak. The official provider/pin is unchanged and the production
   failure remains. See the [unapplied proposal and evidence](../capture/provider-proposals/README.md).
4. **Original iOS Capture is missing six declared implementations.** Real
   consumers retain all public symbol references. No placeholder functions,
   removed declarations or excluded platform rows make the missing code pass.
5. **CNet/Crypto production ownership is incomplete.** Existing M5 test-only
   isolation does not establish one production TLS owner or complete the
   original Crypto wrapper migration.
6. **SDK publication admission and runtime closure are incomplete.** Target
   names, compile-database filenames and a manifest's self-reported execution
   label cannot certify a release. Explicit implementation blockers keep
   publication off even if the editable deferred list is cleared. Native
   dependency redistribution and clean installed-runtime tests remain required.

The version plan is documented in [RELEASING.md](RELEASING.md): display/tag

Candidate workflow artifacts are for review; no candidate success is permitted
to mark the full migration complete or publish this version automatically.
